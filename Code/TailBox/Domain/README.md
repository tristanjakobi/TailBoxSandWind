# Domain

Pure TailBox utility semantics live here:

- Tailwind-shaped candidate parsing.
- Candidate diagnostics and unsupported reasons.
- Theme/token resolution.
- Utility declaration generation.
- s&box style capability checks.
- Selector and arbitrary-value text helpers.

Do not add application DTOs, source file paths, project filesystem access, editor APIs, or generated file rendering/writes to this layer.
